LANboard V2.3 — glass keyboard (authoritative visual reference; matches spec §6.7). Static 3D glass: neutral glass = character keys, cyan glass = command keys (shift / backspace / ?123 / enter); globe = muted utility; terminal row = lower-profile cyan glass; spacebar uses the flattened wide-key sheen. Tap/hold a letter for the floating glass key-preview popup; every key has the depress + one-shot press glint (no ambient shine). Faux-glass on keys; real backdrop blur is reserved for floating surfaces (picker, toolbar-on-expand, popups).
