§5.6 quick preset picker — authoritative render contract (V2.5). The picker is a single full-strip floating glass scrim (blur(14px), radius 12, the §7.4 banner's shadow + inset top lip, cyan-glass fill — never amber) carrying, right to left: the inert cyan "you are here" float (always the cyan signature regardless of active preset — marker treatment: solid fill, dark ink, soft glow, no bright top-lip, no lift shadow), then the alternative pills (neutral V2.3 glass, 30dp tall, 13dp identity dot, max-width 118dp with tail ellipsis), then the far-left two-state utility tile (gear, or "…" + a cyan "+N" count chip when presets are hidden). Pills sit nearest-ring-first in the global §8.1 order. The open is a one-shot staggered right→left reveal (~220ms, 45ms/element) that settles static — compliant with the §13.2 wave ban by the same carve-out as the press-glint: it fires once on gesture-begin, never loops, never idles. Resolve: armed pill (cyan border + 1dp lift + 1.03 scale) → lift → float label updates and plays the pinned cyan scale-pulse (~150ms) → overlay retracts (~200ms) → the mic icon crossfades to the landed preset's color (~200ms, one-shot; plays on auto-apply tint changes too — the pulse is manual-only). Hit rule for the sliding finger: each pill's armed region is its width plus half the 7dp inter-pill gap on each side, at the full 44dp strip-band height — the 30dp pill is the visual, not the target.
